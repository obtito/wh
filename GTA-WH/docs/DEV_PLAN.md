# GTA-WH · 武汉江城 · 开发计划(可执行版)

> 上位文档:[武汉开放世界开发计划.md](./武汉开放世界开发计划.md)(方向与玩法定位)
> 本文档是落地到文件与验收标准的执行计划。

## 0. 结论先行(技术决策)

| 决策项 | 选择 | 理由 |
|---|---|---|
| 技术路线 | **Three.js + 原生 ES Modules,无构建步骤** | 参考本地 GTA-NJ(南京版)已验证的路线;离线可跑、迭代快、无 npm 网络依赖(本机 GitHub 502、Overpass 不稳) |
| 参照系 | GTA_SZ(Babylon+Blender 管线)的**思路**,GTA-NJ(Three.js 离线)的**骨架** | GTA_SZ 的数据分层(骨架层/景点层/交互层)与「本地原点+统一缩放」直接继承;Blender/GLB 管线过重,弃 |
| 比例尺 | **1 单位 = 1 米(全真实尺度)** | 本作有车辆驾驶玩法(车速 m/s、车长 4.6m),真实尺度物理直观;GTA-NJ 的 1:100 压缩不适合驾驶 |
| 坐标 | 高斯-克吕格投影(移植 GTA-NJ geo.js),原点 **(114.295, 30.560)**(两江交汇·龙王庙附近) | 武汉三镇几何中心,东西 ±14km、南北 ±10km 内精度充足 |
| 地图数据 | Google Maps 参考坐标(录入 `data.js`,标注"约测")+ OSM 拓扑记忆 | Overpass 现网不稳;武汉骨架(两江三镇、主干道轴线)手工录入可控且可校验 |
| 城市/植被 | 程序化生成(分区建筑 + 实例化) | GTA_SZ/NJ 同款思路:底图程序化,**地标单独精建**并在占地范围内排除程序化建筑 |

## 1. 武汉地理骨架(数据口径)

### 1.1 水系(骨架层的锚)
- **长江**:西南→东北穿城。控制点:(114.215,30.497) 白沙洲南 → (114.255,30.512) → (114.2786,30.5222) 鹦鹉洲桥 → (114.2762,30.5732) **龙王庙两江交汇** → (114.3088,30.6017) 二桥 → (114.3420,30.6290) 二七桥 → (114.380,30.650) 天兴洲北汊
- **汉江**:西南→东北入江:(114.180,30.523) → (114.225,30.543) → (114.252,30.553) → (114.270,30.564) → 龙王庙
- **东湖**:湖面多边形 30.525–30.60N, 114.365–114.48E(含郭郑湖、汤菱湖、后湖三域简化)
- **沙湖 / 水果湖 / 南湖 / 月湖 / 莲花湖**:内湖按多边形
- **楚河**:沙湖→东湖人工渠(114.334,30.561)→(114.352,30.559),汉街沿线

### 1.2 山体(武昌丘陵)
蛇山(黄鹤楼所在,东西向山脊 114.285–114.310,主峰约 85m)· 龟山(汉阳,主峰约 90m)· 珞珈山(武大,约 118m)· 磨山(东湖,约 116m,楚天台)· 洪山(约 70m)· 凤凰山(武昌,约 40m)· 喻家山(约 150m)

### 1.3 主干道轴线(真实走向,宽 40–70m)
- 汉口:沿江大道 / 中山大道 / 京汉大道(轻轨高架)/ 解放大道 / 建设大道 / 黄浦大街
- 武昌:临江大道 / 民主路 / **武珞路—珞喻路**(东西主轴至光谷)/ 中南路—中北路 / 徐东大街 / 东湖路—楚汉路
- 汉阳:鹦鹉大道 / 汉阳大道 / 龙阳大道
- 过江:长江大桥 / 二桥 / 鹦鹉洲桥;汉江:江汉桥 / 晴川桥 / 月湖桥

## 2. 模块结构(GTA-WH 根目录)

```
GTA-WH/
  index.html            入口 + importmap + HUD DOM
  css/style.css         玻璃拟态 UI
  js/
    geo.js              高斯投影/噪声/太阳(sunState)/几何工具 —— 移植 GTA-NJ,改武汉原点、米制
    lib.js              材质缓存/程序化贴图/实例化/合并 —— 按 GTA-NJ 裁剪改写
    data.js             武汉唯一数据源:水系/山体/道路/分区/地标(含坐标与实测 spec)
    world.js            地形(七山)/水面 shader(长江汉江东湖)/道路网
    city.js             分区建筑/行道树/车流(实例化)
    arch.js             中式古典构件(攒尖/飞檐/斗拱/台基)——黄鹤楼、晴川阁、归元寺用
    bridges.js          长江大桥(公铁双层)/二桥(斜拉)/鹦鹉洲(三塔悬索)/汉江桥群
    landmarks.js        16 处地标构建器
    vehicle.js          街机车辆物理 + 追尾相机(驾驶玩法核心)
    player.js           步行模式(第三人称小人)+ 上下车
    flycam.js           无人机自由飞行
    game.js             玩法状态机(驾驶/步行/飞行)、POI 打卡、观光任务
    hud.js              小地图(canvas)/速度表/打卡卡片/帮助
    environment.js      程序化天空 → PMREM 共享环境(移植 GTA-NJ)
    main.js             装配 + 主循环 + 昼夜
  vendor/               three.module.js / OrbitControls.js / Sky.js(本地化)
  tools/
    serve.mjs           no-store 静态服务器
    check.mjs           纯语法解析预检(vm.SourceTextModule)
    smoke.mjs           构建冒烟:投影/水域连通/道路桥接/地标高度校验
    mapplot.mjs         几何真值平面图(PNG)——肉眼校验城市骨架
  docs/                 计划与依据文档
```

## 3. 阶段计划与验收标准

### P0 骨架(先行)
- [ ] vendor 本地化;index.html + css + main.js 最小场景(天空/地面/昼夜滑杆)
- [ ] tools/serve.mjs + check.mjs
- **验收**:`check` 全绿;浏览器打开见天空+地面+太阳随时间移动

### P1 地理底座
- [ ] geo.js(米制高斯投影,原点 114.295/30.560)
- [ ] data.js 水系/山体/道路/分区坐标录入
- [ ] world.js:地形高度场(七山)、江面 shader(波浪+菲涅尔+夜色)、湖群、主干道网(drape 贴地)
- [ ] tools/mapplot.mjs 出骨架平面图
- **验收**:mapplot 上两江交汇形态、东湖轮廓、武珞路—沿江大道等轴线走向与真实地图目视一致;水域不穿山

### P2 三镇城市
- [ ] lib.js 材质/贴图/实例化;city.js 分区建筑(风格表)+ 行道树 + 车流
- [ ] 地标占地排他(建筑避让桥线/景区/水域)
- **验收**:冒烟测试统计建筑数 8k–30k、draw call 合并后 < 200;60fps(中端 GPU)

### P3 地标精建
- [ ] arch.js 中式构件库 → **黄鹤楼**(攒尖顶+逐层收分+台基)
- [ ] bridges.js:**长江大桥**(桁架+双层+铁路列车动画)先行,再二桥/鹦鹉洲/汉江桥群
- [ ] landmarks.js 其余地标
- **验收**:黄鹤楼/大桥/绿地中心总高与实测误差 < 8%;桥面与道路网高程衔接无悬空

### P4 玩法闭环
- [ ] vehicle.js(加速度/转向/漂移手感/贴地)+ player.js(F 上下车)+ flycam.js(G)
- [ ] game.js POI 打卡(靠近弹卡)+ 观光任务链(环线:江汉关→江滩→大桥→黄鹤楼→省博→东湖)
- [ ] hud.js 小地图 + 速度表;昼夜循环(N 键/自动)
- **验收**:能开车从汉口经大桥到武昌黄鹤楼下;任务链可完整走完;三种模式切换无卡死

### P5 夜景与打磨
- [ ] 夜间窗光/桥体亮化/黄鹤楼金色泛光/江滩灯光带;雾;远景 LOD
- **验收**:18:00–22:00 视觉可辨;帧率不塌

### P6 交付
- [ ] README.md(运行方法/操作说明/数据口径与版权:THREE.js MIT、OSM 衍生说明、GTA_SZ MIT 致谢)
