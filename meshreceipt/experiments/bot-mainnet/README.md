部署钱包与 immutable 验收者固定为 `0x83ECdf7b1Ce06b17558a8DA188579be2AD2Ab512`；Chain ID 固定 677；全部交易 value 为零；累计 Gas 预算 0.05 BOT。没有私钥输入、API Key 或自动签名。

```sh
node --test experiments/bot-mainnet/test.js
node experiments/bot-mainnet/serve.js
```

脚本先重新验签和复算冻结的原交付包、校验固定哈希，并编译已经审查的修复合约。构建到全新系统临时目录，监听全新 127.0.0.1 随机端口，只提供该目录的静态文件。不会将原数据或项目根目录公开。

在 Chrome 中打开输出的网址，使用 **OKX Wallet**。切换/添加 677 主网、连接钱包均由本人操作。连接只读核对主网、钱包、余额和已有交易；每笔分别预估、核对、签名，签名按钮绝不自动点击或连续执行。

预算包含已确认交易实际费用、本笔最高费用和后续保守预留；发送前再次核对。页面提交的部署/任务/回执 Gas 安全上限分别 600000/120000/190000，签名前限制保持不变。未能查询、余额不足、超预算、错误链/账户、待确认交易、nonce 改变或源码变化时停止。页面不能阻止钱包在确认框中调整参数；本人仍需核对钱包的最高费用，不主动改 Gas、不加速或取消，也不另行发送交易。

页面保存交易哈希和发送意图来防止重复发送；恢复时重新读取链上交易、状态、代码、固定验收者及交付哈希，不信任缓存为新验证。发送结果不明时停下，粘贴真实交易哈希恢复；失败交易不自动重试。不要清除浏览器存储后重部署，丢失记录应先找回已签交易。
